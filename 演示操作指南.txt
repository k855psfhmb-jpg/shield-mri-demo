SHIELD 非增强 MRI 智能筛诊演示：操作指南

一、使用前请确认

本系统是预置病例和预计算结果的演示原型，不运行 AI 模型，不对新病例进行推理，也不能自动生成虚拟增强、分割或诊断。病例 01、02、03 的类型文字仅为预定占位，不能作为病例结论。没有素材的栏目显示“待补充”，不表示阴性。

三例真实病例及其预计算结果需由课题组准备，导入前应确认使用授权、完成脱敏，并逐项核对病例、序列、期相、标注、征象和报告。不要把姓名、身份证号等可识别信息或未经授权的病历资料用于演示。 即使已拒绝 EXIF，图片其他元数据及图像像素中仍可能包含烧录的身份信息；系统不提供自动脱敏，须由课题组复核。文件校验或内容指纹只能协助识别和检查文件，不能证明患者归属、医学结论或影像配准正确。

目前比赛预览网址为私有访问，不能直接作为无需授权的组委会访问链接。离线网页包不是 Windows .exe 安装程序；组委会是否接受离线包、预置结果以及是否要求现场处理未知病例，均需向组委会确认。

二、在 Windows 上打开离线工作台

1. 将压缩包完整解压到本地文件夹，不要在压缩包内直接运行。请保持 index.html、case-data.js、viewer.js、app.js、report-backup.js、report-clear.js、presentation.css 及其他文件在解压后的相应位置。
2. 双击 index.html，进入首页后点击“进入演示工作台”；推荐使用新版 Microsoft Edge 或 Chrome。网页和病例包读取不需要联网。首次使用前请在比赛用 Windows 电脑和浏览器上实测；其他系统上的测试不能代替 Windows 真机验证。
3. 左侧的病例 01、02、03 分别对应 CASE-01、CASE-02、CASE-03。点击病例，再点“导入当前病例包”，选择该编号对应的 JSON 文件。编号不一致的文件会被拒绝。
4. 病例包只在当前页面读取；刷新或关闭页面后，影像与结果需要重新导入。导入时遇到错误，请阅读左侧提示并检查文件；错误文件不会作为有效病例导入。
5. 如仅需查看一张静态图片，可展开“临时载入单张影像”，选择序列并载入；此方式不会套用旧病例结果。请下载临时病例包并在确认文件存在后点击确认，报告编辑内容需另行备份。要在其他浏览器或电脑恢复报告，须先导入同一病例包，再恢复对应报告备份。

三、制作和核对病例包

1. 在工作台左侧点击“制作病例包”，打开本地制作页面。选择目标病例槽位，记录生成的病例包 UUID。更换患者必须使用新的 UUID。
2. 分别选择同一病例的非增强序列图片和对应的预计算虚拟增强动脉期、门脉期、延迟期图片。不得把真实增强图像标为虚拟增强结果。只支持方向已校正、无 EXIF 的静态 PNG、JPEG 和 WebP；不支持 DICOM、NIfTI、APNG 或动画 WebP。单张图像不超过 8 MiB、最长边不超过 8192 像素、总像素不超过 16777216；每例最多 150 张、图片总像素不超过 201326592，生成的 JSON 不超过 35 MiB。这些是演示性能限制，不是医学标准。
3. 各组初始按文件名自然排序；展开文件列表可上移或下移切片，并核对文件名和 imageId。同次选择内调整顺序不会改变图片的 imageId；重新选择整组图片会产生新 imageId，旧标注和征象证据需重新关联。浏览顺序不表示不同序列或期相已配准。
4. 病灶、征象及结构化报告可在制作器表单中填写，也可在“高级 JSON 输入”中补充；字段和归一化坐标说明见“病例数据格式说明.txt”。不填写表示待补充，不代表无病灶或阴性。征象未指定 lesionId 时为病例级，不自动归属某个病灶。
5. 核对并勾选确认后，点击“校验并下载病例包”，在浏览器下载列表确认 JSON 文件已保存，再回到工作台，选中相同病例编号并导入。制作页面和工作台均不替代人工确认，请在目标演示机上逐图复核显示方向和标注位置。

四、现场演示

1. 按病例 01、02、03 顺序分别导入各自病例包。点击“查看三例素材清单”，检查非增强、三期、标注、征象和报告是否已载入。清单只统计素材是否存在，不验证医学正确性，也不表示影像已配准。
2. 选择一个病例，按页面下方的“虚拟增强 → 病灶检出 → 关键征象 → 诊断输出”逐步点击。也可点“一键流程回放”自动切换，过程中再次点击可停止；这只是回放界面步骤，不是模型运算。
3. 在虚拟增强中可选择“原图对照”并切换期相，或选择“三期并排”。影像窗口内的左右箭头、滚轮或方向键切换该组图片；右下角缩放控制作用于全部窗口，放大后可在图像上拖动，双击复位该图位置，点击“全部适配”复位所有窗口。各序列与期相独立切换，系统不自动进行同层匹配或配准。
4. 在病灶检出中选择病灶，可分别勾选定位框和分割轮廓；“定位到标注”可跳至该病灶已有标注的影像。标注只在其关联的 imageId 上显示。没有标注时显示待补充，不能据此推断未检出病灶。
5. 选择已导入的关键征象，可查看其关联证据；若有多张证据可用左右箭头切换。界面会标明证据来源，缺少证据时不沿用其他图像。没有结果时，页面展示的征象名称只是示例，完整清单待课题组确认。 如团队提供预先画好标注的结果图，制作病例包时须声明底图、病灶及征象关联；工作台会注明图内标注无法单独关闭，也不会宣称已经配准。底图摘要用于检查文件内容一致，不证明医学来源或结论。
6. “诊断输出”显示当前病例的报告摘录；可在右侧编辑检查日期、部位、技术、所见、诊断意见及可选审核信息等字段。空白审核字段不代表已审核；报告内容必须由课题组核对。点击“打印 / 保存 PDF”，在打印对话框中选择打印机或保存为 PDF；报告保留演示标识。

五、报告保存与备用

报告编辑内容保存在当前设备的当前浏览器中；网页预览与本地文件、不同浏览器及不同设备的存储不互通。清除浏览器数据会删除相应本地报告；演示结束后可确认清除此浏览器存储区内的全部 SHIELD 报告；共享同一存储区的其他离线副本也可能受影响，请先备份并关闭其他标签页。清除不会删除下载的病例包或备份；如果页面提示本机保存不可用，请先点击“备份报告”下载备份，再退出或更换病例。

“备份报告”生成本地 JSON；“恢复报告”需要备份中的病例编号、病例包 UUID 和完整文件内容指纹与当前导入包一致，并在确认后覆盖当前报告。请将原始病例 JSON 与对应报告备份一同保留。即使只重新格式化或更改病例包的空格，文件指纹也会变化，旧备份不会自动匹配。 如果确实是同一病例和同一个病例包 UUID 的更新版本，可使用“核对迁移旧备份”查看旧报告及两个指纹，人工逐项确认同一患者和内容后，再选择是否覆盖当前报告；不同病例编号或 UUID 无法迁移。相同编号或 UUID 本身不证明是同一患者。打印报告中的指纹用于区分文件，不证明来源或医学结论。

六、演示前检查

在正式演示设备上预先断网测试解压、打开、三例逐一导入、四步切换、图像方向与标注、征象和报告、备份恢复及打印。演练所用的合成几何图或测试文字只应保留在测试环境，不能混入正式演示病例。现场演示前再次核对三例素材和报告；当前系统不具备未知病例的真实推理能力。

报告编辑建议只打开一个 SHIELD 标签页。若显示“报告保存冲突”，本页输入保留但尚未写入本机：先用“备份报告”保存本页内容，关闭其他标签页，再点击“读取本机最新报告”；此操作会丢弃本页内容，需先核对备份。冲突检查不能保证多标签页同一瞬间写入时完全互斥，不能代替单页操作。
若报告过长导致 JSON 备份失败，可使用“导出报告文本”保存本页全部字段作人工备份，并确认文件已下载；该文本不能直接恢复到系统。文本导出也失败时，请手动复制各字段到安全位置。

离线双击打开时，浏览器对 file: 本地页面的存储处理可能因浏览器和版本而异；换浏览器、路径、设备或清除浏览器数据后，报告可能不可见。请在比赛用 Windows 电脑上测试关闭重开，并保存原始病例包及报告备份，不要只依赖自动保存。参考：https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage

性能演练：单例允许的最大图片数量或像素并不意味着比赛电脑能同时流畅载入三例。请在最终 Windows 电脑上离线导入实际三例并完整回放，留意卡顿或内存不足；如有问题，由团队挑选演示必需的切片并重新制作病例包，再逐图核对方向、定位框、轮廓和征象证据。

病灶信息可展示病例包提供的预置良恶分类；未提供时显示“待补充”，该显示不构成病理结论。关键征象置信度的定义须由课题组提供，目前不会自动生成。

切片顺序：制作器初选后显示文件名、imageId 和切片顺序，可用上移/下移人工调整；同一次选择中，调整顺序不改变图片自己的 imageId。重新选择一组图片会分配新 imageId、清空预绘制结果底图选择；旧标注和征象证据需要按新列表重新关联。顺序及编号不会证明不同序列同层或已配准，必须人工核对。

素材核对：制作器会在本地列表显示文件名。演示前请由课题组检查文件名、图像像素中烧录的姓名或检查号以及其他元数据，并按团队要求完成脱敏；移除 EXIF 本身不等于完成脱敏。

图片快照：制作器会在选择后依次读取并在当前页面内存中固定图片内容；等待读取完成后再重新核对、勾选确认。外部修改原文件不会自动更新页面，若需使用修改后的图片，必须重新选择并重新关联结果。每例制作时普通图与结果图合计最多 150 张、单张最多 8 MiB、原始图片总量约 26.24 MiB；最终 JSON 还须不超过 35 MiB，实际内存占用可能更高。快照刷新后不会保留，请确认下载病例包。

制作器中展开“文件、imageId 与顺序”，可点击“查看”预览已读取的图片快照，同时核对序列、顺序、文件名与 imageId；预览仅供人工核对，尚不代表通过格式校验、同一病例或完成配准。

病例包下载发起后，请到浏览器下载列表确认对应 JSON 文件确实存在，再点击制作器中的“我已确认病例包文件保存”；此操作仅解除当前版本的离开提示，之后修改任何素材会重新启用保护。取消下载或无法确认保存时不要点击。
取消文件选择时，制作器保留原快照并在选择框附近显示当前状态；需要使用外部修改后的同一路径文件时，重新选择该文件并等待快照读取完成，再重新核对关联。

批量载入：可点击“一次导入三个病例包”，同时选择恰好三个 JSON；系统按文件内的 CASE-01、CASE-02、CASE-03 分配，不按文件名或选择顺序推断。校验任一文件失败或编号重复会保留原病例；通过校验后逐例显示导入或跳过结果，请关闭对话框后逐例核对。读取中可取消，已完成或未更改情况以界面为准；当前后台处理结束前不能再次发起批量导入，但可以关闭对话框并使用单例导入。批量载入仍需本地选择文件，并非自动预装或模型推理。

可选：在比赛电脑双击 browser-check.html，可离线检查部分浏览器基础能力；即使全部显示通过，也不能替代工作台关闭重开、三例真实素材、打印/PDF 和现场设备验收。

恢复或迁移报告时只接受不超过 2 MiB 的有效 UTF-8 JSON 备份；编码损坏会拒绝恢复，当前报告保留。
