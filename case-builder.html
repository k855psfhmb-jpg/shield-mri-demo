整理一例预置病例

选择已准备好的影像图片和结果，生成工作台可读取的 JSON 病例包。全过程在当前浏览器本地完成，不运行模型。

仅使用经授权的脱敏材料。本工具不支持 DICOM 或 NIfTI；请先准备方向已校正、不含 EXIF 的静态 PNG、JPEG 或 WebP。首次选择按文件名排序，可在文件列表中手动上移或下移。顺序须由团队核对，不代表序列或期相已配准；重选一组图片会为新文件分配全新 imageId，旧标注与证据引用须重新核对。请由团队核对病例、影像、期相和结果。EXIF 检查不是自动脱敏；PNG 文字元数据和图像中烧录的身份信息仍须另行核查。

01 · 病例身份

更换患者时必须生成新的 UUID。修改素材后，包内容指纹会改变，旧报告不会自动套用；请保留原始病例包和对应报告备份。

02 · 非增强影像

为每个序列选择同一病例的静态图片，可选多张；每张图片最大 8 MiB、最长边 8192 像素、总像素不超过 16777216；每例最多 150 张、图片总像素不超过 201326592。

03 · 预计算虚拟增强结果

仅放入对应病例的虚拟增强结果。请勿把真实增强影像标作虚拟增强；未准备的期相可以留空。

04 · 可选：预绘制结果图

可添加团队已绘制标注的结果图，并明确指定所属病灶或征象及关联底图。图内标注不能单独开关；底图关系由团队声明，不表示自动配准；系统记录底图文件摘要以防内容错配，该摘要不证明医学来源。病灶和征象可在下方表单添加，也可通过高级 JSON 定义；请填写对应 ID。增删或重选底图后，须重新选择关联底图。

05 · 可选：病灶、征象与报告

不填写时均视为待补充，不代表阴性。表单与高级 JSON 会合并，病灶及征象 ID 不能重复；表单的病灶选择列出通过表单创建的病灶。高级内容使用 JSON，imageId 请参照上方每组列表。征象 lesionId 缺失或 null 表示病例级；填写时必须引用已有病灶 ID，不会自动归属。字段格式见 病例数据格式说明。

病灶（可选）

添加后获得病灶 ID；可展开该病灶的标注 JSON，或使用预绘制结果图。这里不自动生成诊断。

关键征象（可选）

结果默认待补充；证据 imageId 请参考上方文件列表，多个用逗号分隔。删除关联病灶后须重新选择归属。
