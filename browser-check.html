SHIELD 浏览器基础自检

可选工具 · 使用本机合成数据 · 无需联网 · 不读取病例或报告

这不是 Windows 或比赛验收。本页仅检查少量浏览器基础能力，不能验证工作台关闭后的报告持久化、真实病例、图像方向与配准、大图性能、打印或 PDF、网络可用性、比赛规则和现场模型推理。请在比赛 Windows 电脑上按操作指南完整演练。

自检脚本尚未执行；若提示持续显示，请完整解压并使用新版 Edge 或 Chrome。以下项目均未检测。

  • JavaScript 执行未检测
  • SHA-256 已知向量未检测
  • 严格 UTF-8 解码未检测
  • File 与 Blob 字节读取未检测
  • PNG 显示与 Canvas 读取未检测
  • JPEG 显示与 Canvas 读取未检测
  • WebP 显示与 Canvas 读取未检测
  • 对话框未检测
  • 本测试页本机存储即时写读未检测

存储测试仅写入并删除一个随机临时键，不读取或清除 SHIELD 报告。不同本地页面的存储范围依浏览器而异；本页即时写读通过不证明工作台持久保存、关闭后恢复或不同副本相互隔离。
